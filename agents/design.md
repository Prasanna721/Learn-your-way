# Design System

## Colors

**Primary Background**
- Sand: #f6efe9 - Main page background

**Coral Palette** (lightest to darkest)
- Lightest: #fef5f2 - Subtle backgrounds
- Lighter: #fce5dc - Light interactive elements
- Light: #f9d0c4 - Buttons, interactive elements
- Coral: #f6ae96 - Primary accent, hover states
- Strong: #ee9a7e - Strong hover, emphasis
- Dark: #e6866a - Borders, call-to-action
- Darkest: #d96f51 - Active states

**Text**
- Primary: Black (#000000)
- Secondary: Black with 70-80% opacity

## Buttons

**Icon Buttons**
- Size: 40px × 40px
- Shape: Fully rounded (circular)
- Background: #f9d0c4 with hover to #f6ae96

**Pill Buttons**
- Padding: Various (20-32px horizontal, 10-16px vertical)
- Shape: Fully rounded (pill-shaped)
- Background: #f9d0c4 with hover to #f6ae96

**Call-to-Action Buttons**
- Shape: Fully rounded (pill-shaped)
- Primary accent color: #f6ae96

## Typography

**Headings**
- Large: 22-28px on mobile, larger on desktop
- Weight: Semi-bold or Bold

**Body**
- Size: 16px (base)
- Weight: Medium

## Spacing

**Layout**
- Header height: 80px
- Container padding: 16-24px horizontal, 24px vertical
- Element gaps: 8-12px

**Border Radius**
- Buttons: Fully rounded (pill/circular)
- Cards/Dialogs: 16-24px
- Dropdown items: 16px (rounded on appropriate corners)

## Transitions

- Standard: 200ms for all properties
- Interactive elements should have smooth hover states
- Use ease-in-out timing function

## Design Language

Modern and clean aesthetic with warm coral tones. The design emphasizes:
- Soft, approachable colors from the coral palette
- Rounded corners and pill-shaped buttons for friendliness
- Clear typography hierarchy with medium to bold weights
- Generous spacing for breathing room
- Smooth transitions for polished interactions
- Minimalist approach with focus on content
